## ★ 关键配置函数剖析

函数：`selectConfig(ConfigModule, Config)`（按实际函数名填写）

| 维度 | 内容 |
| --- | --- |
| 来源 | 实际 import 和定义；框架 / 第三方包 / 项目封装，依据可核对 |
| 入参 | 实际类型及业务含义；不要套其他包的签名 |

## ◆ 配置内部流程

加载（env / yaml / 工厂）→ 合并默认值 → 项目覆写 / 校验 → 注册为 Provider → 取出 / 注入 → 使用点（读字段、初始化、决策）。

逐层标注哪些是框架默认、哪些是项目覆写；不把项目覆写当成框架默认。

## ○ 未知与验证前提
