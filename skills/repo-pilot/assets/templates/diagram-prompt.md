# 可选图示风格

仅用户要求图像、品牌或手绘时使用；默认清晰文字/Mermaid见[图示契约](../../references/contracts/diagrams.md)。

输入：已确认节点/关系、短标签、待确认边、用户视觉偏好。
提示：创建清晰平面结构图，充足留白，短标签，颜色只辅助分组，关系用文字/线型。保留未知虚线与图例，不增添数据库/网关或未确认参与者。图下源码位置映射另由Markdown承载。

如用户要求RepoPilot品牌：深蓝描边、青蓝重点、纸白背景，可有轻微手绘笔触；文字优先，装饰克制。时序图以技术清晰为先。品牌是可选表现参数，不是每项目的分析要求。

## 可填写内容约定

先填以下内容，再选择一个风格片段。换风格复用这份清单，不重新发明技术关系。

```text
用途与读者：[上手/架构维护/某个动作；读者已有知识]
唯一认知目标：[看完能回答哪个问题]
图类型与阅读顺序：[结构/流程/时序；左到右/上到下等]
节点：[ID、精确短标签、角色分组]
关系：[来源ID、目标ID、类型、条件、确认状态]
边界：[未读/动态/外部关系；必须保留的断点]
布局与比例：[适合内容且宿主支持的布局/尺寸]
风格：[下列一个片段或用户明确偏好]
禁止补全：[不增加数据库/服务/步骤，不改变语义，不制造运行结论]
交付用途：[Markdown图源/图片候选/实际可编辑对象等可用能力]
图外证据：[节点/边ID到实读文件、符号、行号的映射]
```

模板可用于宿主已有图片/设计工具，不绑定供应商、模型或 API。无图像工具时遵循图示契约降级。短标签预先核对，长路径留在图外；不要让生图模型从整个仓库猜架构。

## Logo 手绘地图片段

为新人绘制项目结构/流程图，视觉参考手绘地图导航：深海军蓝轮廓，线条粗细轻微变化；亮蓝与青蓝柔和水彩色块，纸白与极浅蓝底色；少量地图折线、路线与圆形定位点。整体平面清爽，轻微纸面笔触，文字短而清晰，留白充足。地图元素仅作小装饰，不代替模块，不改变图例或真实关系；不用照片、3D、重阴影或彩虹色。

主路径用亮蓝强调，分组浅蓝填色，轮廓海军蓝。节点 ID、短标签、条件和未知严格按内容约定；不把 import 画成已执行调用，不把 Provider 包裹画成时序。

建议调色：#061A66 / #087BFF / #20CEF4 / #DCEEFF / #FAFCFF。它们是从品牌视觉提炼的建议，不是 logo 的精确采样值。

## 清晰平面片段

为维护文档绘制清晰平面结构/流程图。白色或极浅底色、深色直线轮廓、统一间距与字号，少量蓝色区分主路径和角色；关系同时用短标签说明。节点对齐、分组明确、留白充足；不使用水彩、3D、照片、厚重阴影或装饰卡片。保留内容约定的节点、条件与未知，位置在图外。

## 时序片段

绘制普通清晰技术时序图，不强制手绘。按给定参与者、消息、参数来源、条件、返回与异步关系组织；只有来源支持才画循环，不添加数据库或服务凑完整。源码分析标“静态预期顺序，未运行验证”。参与者/消息到源码位置的映射在图外提供。

## 忠实来源片段

以用户提供且已查看的图为视觉来源，保留对象身份、标签、布局顺序、颜色含义与连接方向。列出无法识别的标签，不凭画风猜关系；只调整用户要求的部分。若要求可编辑对象，明确哪些实际构建为文本/形状/连接线，哪些仍是局部图片。未构建不声称可编辑。

## 检查与实际交付

对照清单核对标签、方向、条件、未知与证据，多图角色色和术语一致，放进主文后仍可读。只按实际产物写状态，提示词不是 PNG，图片不是可编辑 PPT。需要追溯时才保留本次真实提示词/结果与工具可得元数据，不默认生成模型请求 JSON、质检包或演示文稿。
