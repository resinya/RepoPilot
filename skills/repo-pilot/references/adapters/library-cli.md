# 库与CLI适配

1. **确认身份**：bin/main/入口点、公共导出、脚本/模块清单。完成：可执行应用与被消费库区分；有package.json不必有UI。
2. **入口到处理**：命令注册/参数校验→纯核心处理；库看导出→消费者→核心实现。完成：真正处理与包装/聚合出口分开。
3. **结果边界**：stdout/stderr、退出码、文件/网络写入、返回值/异常、资源清理。完成：静态副作用已识别，未执行不称产物生成成功。
4. **扩展与验证**：相邻命令/格式/导出、公共API兼容、现有测试和打包。完成：阅读路线能支持一个小需求，命令来自清单。

没有第三方库时明确使用运行时内置能力，不凑技术栈；运行时版本未知写未知。图从真实入口到输入输出，无页面/Router/数据库固定章节。[完整CLI案例](../examples/cli-library.md)可校准。
