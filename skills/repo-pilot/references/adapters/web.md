# Web 适配：浏览器入口与页面关系

只在浏览器应用证据成立时读。执行顺序由[onboard](../workflows/onboard.md)负责；这里替换入口/结构读法，不定义另一套上手阶段。

## 识别和读取顺序

1. 清单＋构建入口/HTML或框架页面约定，确认浏览器应用和实际框架。完成：不能仅由react依赖认定Web，RN可能用同名框架。
2. 挂载/约定入口→全局包装/初始化→路由/外壳→一个页面，附关系和提前返回条件。完成：至少一个真实入口链或明确断点。
3. 页面→事件/数据来源→状态/请求封装→消费者。完成：缓存、服务描述、传输分别解释，页面包装不当调用顺序。
4. 项目能力按实际产品定位，不预设必须有拖拽/画布。需要详细页面读取时才读[Web入口专项](scenarios/web-entry.md)。

| 实际证据 | 只读对应资料 |
| --- | --- |
| React/react-dom＋浏览器挂载或约定页面 | [React](frameworks/react.md) |
| Vue/SFC＋应用或框架入口 | [Vue](frameworks/vue.md) |
| 原生注册/Expo/native平台工程 | 改用[原生](native.md)，不当Web |

未知框架用入口注册/约定→调用者/消费者→输入输出通用回退。移动Web另看触摸/响应式/构建目标，不等于原生App；2B/2C不等于终端类型。只静态读，不启动页面验证。
