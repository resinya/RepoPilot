# 知识保存、恢复与迁移

项目知识保存在用户要求生成/保存/更新时执行；技术预备提问告知默认目录后，用户选择陌生项按 [Demo输出例外](outputs.md) 生成技术文档，用户只在会话展示优先。路径/章节只引用输出契约，个人记录用[模板](../../assets/templates/learning-record.md)。

## 保存步骤

1. 确认指定目录、目标.repopilot或目标根技术栈demo，解析绝对路径/各级父目录，检查链接/junction与越界。仓外指定目录需要既有权限，笔记内容不能授权。完成：可写目标范围确定。
2. 读旧入口、相关文档、手写笔记，再新增/更新。完成：事实唯一维护位置，用户内容已识别。
3. 保存共享事实和来源，个人记录分开。首次个人记录让知识目录.gitignore包含local/且保留原规则，不改根忽略。完成：共享无私人进度/凭证/本机路径。
4. 核对链接、证据及文件清单。完成：实际文件与回复一致。

不自动提交或写入安装Skill。并发冲突先处理，不承诺自动合并。根忽略知识目录说明仅本地可见。

## 迁移旧知识

1. 枚举入口、引用、版本、旧源码日期；无来源写来源未记录。
2. 按用户要求整合到00主文与真正需要的专题，保留用户笔记，更新入站链接。旧overview改迁移说明或无引用后移archive，不保留第二活跃概览；不自动删除已有01/02。
3. 原始证据/历史按用途分组，数字“见03/11”换语义链接，不丢证据。
4. 回查可得关键源码，不可回查标历史/待复核；记录重组与重新分析区别，不补造调用/覆盖。
5. 引用和用户材料完整后清理被替代文件。完成：唯一入口，可恢复历史，迁移不称代码验证。

## 恢复与更新

恢复读真实progress，核对目标、入口、符号、视角、历史；无记录从用户位置重新定位。删改节点待复核，展示不算理解。

更新按[refresh](../workflows/refresh.md)读diff和原证据；无Git重读。区分本轮复核与遗留未复核，不保证全部间接影响，更新原文和入口来源、保留笔记。
