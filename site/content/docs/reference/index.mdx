## 职责

| 位置 | 用途 |
| --- | --- |
| SKILL.md | 14个任务路由、学习链路和操作边界 |
| references/workflows/ | 各任务的输入、步骤、产出和停点 |
| references/adapters/ | 按真实入口适配项目类型与框架 |
| references/contracts/ | 证据、讲解、集中输出、质量与任务衔接 |
| references/examples/ | 业务学习、集中地图与其他任务的正反例 |
| assets/templates/ | 主文、单页业务地图与按需专题模板 |
| scripts/inventory.py | 可选只读目录候选扫描 |
| evals/ | 合成项目及行为评估用例 |

一个安装入口按需加载资料，不另装子 Skill。通用规则和项目事实分开。

## 默认集中保存

默认会话展示，要求保存时以目标 `.repopilot/00-start-here.md` 为完整主文，内部目录串起业务、架构、技术、代表场景、规范和开发路线。只需滚动和定位即可读完整个问题。

独立库学习、机制、需求卡、附录和可视化按需增加；交互成果默认 `maps/<主题>/index.html`，同页展示职责与完整当前场景。只要一份独立页面时无需再生成一份重复说明或索引。

个人进度放 local；更新前先读已有笔记，不自动删历史01/02，不写回Skill。

## 验收

关键结论可追源码；结构关系不当执行顺序；数据逐跳有含义。每轮源码带读一个问题，支持跳过；核心内容不要求点开多个模块才能读懂。

页面语法、交互、布局与真实业务运行是不同验证范围，分别报告。没有运行服务不能把静态链路叫跑通。

```bash
node scripts/validate-skill-metadata.mjs
python -B -m unittest discover -s tests -p 'test_*.py' -v
claude plugin validate .
```
