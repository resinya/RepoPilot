## 四个顶层职责

| 项 | 职责 |
| --- | --- |
| SKILL.md | onboard/map/locate/library/deep/refresh路由、主线与边界 |
| scripts/ | 一个可选 inventory.py，只读目录索引 |
| references/ | 通用参考、adapters；rules集中SOP和框架；examples完整正反输出 |
| assets/ | 上手、库学习、机制、学习记录模板与logo图示提示词 |

一个完整repo-pilot目录包含所有任务资源，不固定文件数，也无需另装子Skill。仓库site、tests、开发规范与企业项目资料不参与安装。rules在references内，由Agent按需读，不增加Node调度入口。

## 前端SOP与输出

项目地图→入口/界面组成→核心能力→需求定位/团队规范→交付。React、Vue、React Native、Unity分别读取结构规则；React有企业静态方法依据，其余真实样本仍待验收。

上手指南是一份有内部目录的主文档，清单按需附录。library生成引用树、流程、常用/项目实际API与项目例子；deep限定内部机制，都是同一Skill参数。examples包含两类完整正反例，展示逻辑连贯与信息拆散的差异。

结构/流程图沿logo的深蓝描边、青蓝填色和地图导航风格；时序图普通清晰。提示词已写在assets中，安装无需根logo。

## 扩展

框架规则说明触发证据、真实入口、领域关注点和未知边界，添加主文件的条件链接。正反例用实际需求说明证据边界；机械操作确有重复再增加脚本。

## 检查

```bash
node scripts/validate-skill-metadata.mjs
python -B -m unittest discover -s tests -p 'test_*.py' -v
```

Node 检查仅属于仓库维护工具。可选脚本用 Python 3.10+ 标准库，主 Skill 不需要安装运行时。测试覆盖边界、预算、只读、复制和链接；真实项目与宿主端到端效果还需验收。

## 笔记

要求保存时写目标 .repopilot/overview.md，个人记录放 local/progress.md 并忽略 local。Skill 更新不覆盖项目笔记。Markdown 保存/恢复由宿主读写完成，不承诺后台自动同步或状态机。
