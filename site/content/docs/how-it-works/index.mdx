Agent 按 SKILL.md 执行，按目标读取当前 workflow 和 adapter。支持资料是内部操作手册；项目交付默认集中阅读，不必逐文件跳转。

## 一条学习链路

1. **onboard**：识别用途、应用边界、模块、架构和核心技术。
2. **business**：用户做什么、模块怎么分工、典型动作怎样完成。
3. **trace**：每步输入从哪来，经过什么处理，输出交给谁。
4. **walkthrough**：要看代码时，每轮一个问题和一个小切片。
5. **locate**：需求先改哪里、照哪处同类实现、怎样验证。
6. **visualize**：需要图时，同页整合职责、完整场景和数据变化。

这些是选择路径，不强制每次走六步。明确的局部需求直接从对应任务开始，复用已读事实。library、deep、teach和refresh负责按需学习及维护；map、architecture、stack、standards提供对应专题。

## 集中呈现

默认会话中完整回答；要求保存时一份主文含内部目录。可视化默认一页显示当前场景全部步骤，关键数据和未知直接可见。导航用于快速定位，只有用户明确要钻取才隐藏到层级视图。

## 小步但不中断

“继续”推进当前问题，“配置知道了、跳过”回业务，“返回”恢复实际阅读历史。Agent可以读完整函数核实，但无需把全部代码贴给新人。陌生技术随场景简报，不先问遍全栈或要求答题。

## 证据与工具

来源分静态确认、推断、未知和运行验证；模块注册不是执行顺序，候选接口匹配不证明部署连通。首次只静态检查；执行依实际授权。

可选inventory只列候选，缺Python用宿主搜索。单页业务地图模板不需构建依赖，也不请求目标服务。
