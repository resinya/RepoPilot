RepoPilot 的运行者是 Agent。没有中间服务、能力探测入口或资源清单解释器。

## 渐进式加载

| 层 | 内容 | 何时使用 |
| --- | --- | --- |
| 发现 | name / description | 宿主选择 Skill |
| 操作 | SKILL.md 的步骤和边界 | Skill 被激活 |
| 细节 | 当前任务的 references | 相应场景才读取 |
| 工具/产出 | inventory.py / assets | 需要目录索引或报告时 |

首轮按仓库范围 → 应用与技术栈 → 关系 → 阅读起点 → 概览 → 入口讲解推进。只问模块时复核相关资料，不重跑全仓流程。

前端按M项目地图→E入口/界面与能力→C需求定位和项目规范→D单主文档/带教执行；命中React、Vue、RN或Unity后只加载相应入口结构规则。阶段不是文件数量，默认一份带内部目录的主指南。

library按相关引用树→概念→真实流程→API对照→项目例子展开；deep按一个动作的参数/状态/生命周期展开。一个Skill的任务参数负责分派，不开启其他Agent或要求另装Skill。

## 一轮源码导览

说明当前位置，读真实代码，解释职责、输入/输出、状态和副作用，给证据及下一候选。默认一个核心节点；自动模式最多三个。渲染、依赖、执行视角分别解释，返回使用阅读历史。

未知关键连接、循环或第三方边界会停止自动深入。运行方式有来源但首次不执行；保存记录需要真实文件，恢复时复核代码变化。

## 降级路径

Python 索引脚本可选，仅列目录项；缺少 Python 时使用宿主读取/搜索能力。它不会解析清单内容、判框架或写知识。失败/预算不足时明确覆盖范围。

新技术栈用 references/adapters 的阅读规则扩展，不改变主流程；重复确定性操作才增加脚本。
