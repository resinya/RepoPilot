## 复制完整 Skill

从源码或发布包取得 skills/repo-pilot 整个目录，保留 SKILL.md、scripts、references 和 assets。当前本地重构尚未公开发布。

| 宿主 | 项目级安装 | 个人级安装 |
| --- | --- | --- |
| Codex | .agents/skills/repo-pilot/ | ~/.agents/skills/repo-pilot/ |
| Claude Code | .claude/skills/repo-pilot/ | ~/.claude/skills/repo-pilot/ |

依据 [Codex](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills) 和 [Claude Code](https://code.claude.com/docs/en/skills#where-skills-live) 文档。目录复制不需要 npm、编译或目标项目依赖。

## 调用

在目标项目开新会话：

```text
$repo-pilot 帮我熟悉一下这个项目
```

Claude Code 使用 `/repo-pilot`。继续时可以要求“返回”“看地图”“看执行视角”“追踪订单”“给我一个练习”。

同一安装目录支持任务参数：

```text
$repo-pilot locate 给列表增加一个字段，哪里改
$repo-pilot library @tanstack/react-query 解释本项目用法
$repo-pilot deep 解释拖入物料如何创建图层
```

Claude Code对应`/repo-pilot library 包名`。这些是Agent按意图选择的内部流程，不是额外宿主命令或独立安装的子Skill。library交付一份库学习文档，deep只分析一个明确机制；代码审查尚未加入。

首次静态探索不会安装依赖或启动服务。Python 3.10+ 仅用于可选目录索引，缺失时由宿主工具完成探索。
