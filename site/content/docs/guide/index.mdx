## GitHub Marketplace

```bash
claude plugin marketplace add resinya/RepoPilot
claude plugin install repo-pilot@repo-pilot --scope user
```

取得的是远程已提交版本；本地改动发布后才可安装到其他机器。插件安装调用 `/repo-pilot:repo-pilot`，直接复制的独立Skill调用 `/repo-pilot`。

## 使用

```text
$repo-pilot 帮我熟悉一下这个项目
$repo-pilot demo RPC 不会，先给最小示例
$repo-pilot business 先讲业务框架与模块分工
$repo-pilot trace 这个动作每步传什么、数据怎么变化
$repo-pilot visualize 把内容集中在一页，不要一直点来点去
```

首次先收到相关技术/包关系清单和熟悉度提问。列出不会的名称或编号，Skill 会先生成目标根 `技术栈demo/README.md` 与每项 `<技术名>/README.md`，完整代码、运行流程和结果集中在该文；也可说“都熟悉/跳过/只在会话展示”。实际落地源码与安装、运行依具体授权。看完说“继续”回原分析位置。

可以直接说“文件太大，每轮只讲一个问题”“配置知道了，跳过”“继续”“返回”。默认会话展示；要保存明确说“整理成一份主文”。

可视化产出一页自包含 HTML，产出标准与自查清单见[业务可视化](/docs/guide/visualize)；常会用到的提法见[使用最佳实践](/docs/guide/practices)。

首次静态读取，不自动启动项目或数据库。可选目录索引用Python3.10+，缺少时使用宿主搜索。
