`visualize` 产出一个自包含的单文件 HTML。判断它是否合格只需一个问题：**不点任何按钮，能不能在这一页答出四件事**——谁传给谁、传了什么、每个字段从哪来、还不知道什么。

导航栏、场景切换、展开源码证据都是辅助。如果一个问题必须点开三个模块才拼得出来，这份产出就不合格。

## 什么时候用它

```text
$repo-pilot visualize 把这个场景做一页可视化，不要一直点来点去
$repo-pilot visualize 每步传什么数据、变成什么
$repo-pilot visualize 这条链路用图说明，不要贴大段代码
```

需要导出图片时按[图示契约](/docs/reference)，默认给 Mermaid 或文字树；只有用户明确要求逐层钻取才用层级视图，且必须保留本页完整摘要。

## 你会拿到什么

| 区块 | 看到什么 | 硬性要求 |
| --- | --- | --- |
| ① 案例与范围 | 一次完整的模拟案例、本次范围、事实状态 | 全文共用**同一组示例值**，不换人换号 |
| ② 完整时序图 | 固定参与者泳道、阶段色带、编号箭头 | 箭头编号与下方卡片编号一一对应 |
| ③ 分阶段数据案例 | 每个大阶段一张卡，内含若干消息 | 所有阶段**同时可读**，导航只滚动与高亮 |
| ④ 模块职责 | 从根展开的职责树 | 子节点是**包含关系**，不是执行顺序 |
| ⑤ 来源与验证范围 | 模拟值声明、未核验项、不可混的实现 | 未知既在页脚，也在对应阶段旁 |

## 案例效果八条

| # | 要求 | 典型反例 |
| --- | --- | --- |
| 1 | 一个连续故事串到尾，同一组例值从头用到尾 | 每段临时起一个 id，读者拼不出同一趟链路 |
| 2 | 参与者按网络进程与存储边界固定，职责写在泳道下 | 用"发送方/当前处理方"混称，或把外部平台与库合成一个"数据" |
| 3 | **重定向拆两跳**：网关到浏览器的 302，浏览器到外部平台的请求 | 画成网关直接请求登录页，等于假装网关替用户持有凭据 |
| 4 | 技术细跳归进 3～5 个大阶段 | 一次技术动作一页，点八次才看完登录 |
| 5 | 数据就近可见：URL、header、对象、存储记录的实际形状 | 卡片只写"输入：用户信息 / 输出：令牌" |
| 6 | **分清谁发送与谁生成** | 把所有字段都归给"请求方传入" |
| 7 | 多个调用合并讲时标"结构汇总"，不冒充一个 API 响应 | 内部参数、缓存记录、HTTP 响应统统叫 JSON |
| 8 | 未知与边界就近标，不在文末免责声明里藏着 | 读者半途已把未确认项当成事实 |

## 一个例子：谁发送 ≠ 谁生成

下面是**合成示例**，用来校准写法，不代表任何真实项目的结论。假设小林进入空间 101，选择了企业身份源；管理员已事先保存接入配置，网关采用授权码方式。

第三阶段的那次跳转是所有 SSO 讲解最容易错的地方：

```text
谁发给谁：认证网关 → 浏览器
传递形式：HTTP 302 响应中的 Location 与 Set-Cookie

Location: https://idp.example.invalid/authorize?
  client_id=<应用接入标识>&redirect_uri=<网关回调地址>
  &scope=openid&state=state-demo-001
  &nonce=nonce-demo-001&code_challenge=<示意值>&code_challenge_method=S256
Set-Cookie: <临时会话名>=session-demo-001
```

| 字段 | 含义 | 来源 |
| --- | --- | --- |
| 空间 101、身份源 corp-sso | 要进哪个空间、用哪个身份源 | 浏览器 URL 路径参数 |
| `client_id` | 外部平台怎么认这个应用 | 管理员事先保存的接入配置，**网关读取** |
| `redirect_uri` | 外部平台完成后回哪里 | 网关按请求与配置构造，并存进临时会话 |
| `state` / `nonce` / `code_challenge` | 关联发起与回调的校验材料 | **网关生成**，浏览器这次没有提供 |

网关是这条响应的发送方，但不是所有字段的最初来源。浏览器拿到 `Location` 后自己去请求外部平台；这是两条箭头，不能画在一起。

同理，回调时的三个东西来自三个地方：授权码由外部平台生成并经浏览器回传，临时会话 Cookie 是网关上一次响应写入的，而期望的校验值来自服务端的临时会话记录。**看完这一段你应该能指出网关永远不必持有用户密码**——这就是第 6 条要达到的效果。

## 常见退化与纠正

| 退化 | 现象 | 纠正 |
| --- | --- | --- |
| 退回概念图 | 满屏一句话卡片，看不到任何真实形状 | 每条消息问一句"读者需要看清传了什么吗"，需要的升级为完整卡 |
| 淹没主线 | 每条消息都带代码块和字段表，扫不出重点 | 中间动作降级为轻量卡，关键数据卡通常占 40%～60% |
| 层级迷宫 | 必须一路点开才看得到数据，返回还丢位置 | 回到本页完整展示，导航只作定位 |

## 自己维护这个页面

页面内容是文件里的一个 JSON 块，没有构建步骤、没有依赖、不请求目标服务。改动前先读模板的渲染脚本。

| 位置 | 字段 | 行为 |
| --- | --- | --- |
| 顶层 | `participants` | 时序图泳道；`role` 超过 15 个汉字会被截断，要写短 |
| 顶层 | `sources` | 来源与验证范围，写清模拟值与未核验项 |
| 场景 | `story` / `legacyStages` | 一次连续案例与开关假设；旧 hash 折算用的下标数组 |
| 阶段 | `summary` / `processing` / `result` / `boundary` | 大阶段的概括、动作、结果和边界 |
| 消息 | `shape` / `fields` | 代码块与"字段、含义、来源"三元组 |
| 消息 | `case` | `false` 为轻量卡，省略或 `true` 为完整卡 |

编号在全部阶段内连续递增，箭头与卡片共用同一个计数器。

```powershell
# Windows：复制模板开始（用 node，避开 symlink 静默失效）
node -e "require('fs').copyFileSync('skills/repo-pilot/assets/templates/business-map.html','<目标>/index.html')"
```

两个必踩的坑：**JSON 里的 `<` 必须写成 `\u003c`**，否则 `</script>` 提前闭合、整页崩掉；Windows 上用 `cp -r` 复制整个目录可能中途失败，改用 node 的 `fs.cpSync`。

## 验收

- 不点任何按钮能读完主场景的全部阶段。
- 箭头编号与卡片编号完全一致。
- 每个字段都有来源，未知写"未记录"而不是留空或猜值。
- 重定向已拆成两个半跳。
- 至少一处明确区分了"谁发送"与"谁生成"。
- 外部令牌、本地凭证、临时会话三者角色被分开描述。
- 场景切换、刷新、键盘、窄屏实测过；脚本无报错，空流程有降级文案。

页面交互通过不等于真实业务运行通过，两者必须分开陈述。
